## 📖 Acerca del Proyecto / About the Project

**Español:**
¡Bienvenido a **Chigüire Studios**! Este es el repositorio oficial del launcher para PC de **Metal Arms: Glitch in the System**. Hemos creado este launcher desde cero utilizando **Electron y React** para ofrecer una experiencia moderna y nativa, eliminando la necesidad de usar emuladores lentos. Nuestro objetivo es preservar este increíble clásico de la era de Xbox, dándole una segunda vida en computadoras modernas.

**English:**
Welcome to **Chigüire Studios**! This is the official PC launcher repository for **Metal Arms: Glitch in the System**. We have built this launcher from scratch using **Electron and React** to provide a modern, native experience, eliminating the need for slow emulators. Our goal is to preserve this amazing Xbox-era classic and give it a second life on modern computers.

## 🛠️ Tecnologías Utilizadas / Technologies Used

Este launcher no sería posible sin las siguientes herramientas:
*   **Electron** (Entorno de escritorio)
*   **React + Vite** (Interfaz de usuario)
*   **Node.js** (Backend y manejo de archivos)
*   **Vercel** (Alojamiento del sitio web)
